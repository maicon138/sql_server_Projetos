# SQL Server - Projetos de Análise de Dados

Repositório com projetos práticos em SQL  Server voltados para análise de dados e resolução de problemas de negócio.

# SQL Portfolio

Este repositório reúne consultas SQL criadas para estudo e demonstração de habilidades em análise de dados.  
O objetivo é mostrar domínio de conceitos importantes para um analista júnior.

## Estrutura
- **joins/** → exemplos de INNER JOIN, LEFT JOIN, RIGHT JOIN.
- **subqueries/** → consultas aninhadas e CTEs.
- **functions/** → funções de janela, manipulação de strings e datas.
- **procedures/** → exemplos de criação de stored procedures.
- **constraints/** → exemplos de uso de chaves primárias, estrangeiras e regras de integridade.

## Como usar
1. Abra os arquivos `.sql` em um banco de dados SQL Server (ou outro compatível).
2. Execute os scripts em tabelas fictícias de exemplo.
3. Explore os comentários dentro dos arquivos para entender cada consulta.

## Integração com Power BI
O arquivo `integração sql e power bi.pbix` mostra como conectar consultas SQL a dashboards interativos.
